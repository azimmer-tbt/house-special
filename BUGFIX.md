# BUGFIX — Toolkit Bug Log

Development log for bugs found in **this toolkit** (scripts, specs, tests, docs).
Entry format and severity/status definitions: `.devagent/rules/05-bugfix-tracking.md`.

Known, verified-but-unfixed issues are summarised in `docs/known-issues.md`; log
the investigation here, then update that list when an issue is fixed or found.

Recipe-specific problems for a customer belong in `customer/<name>/sessions/`,
not here.
