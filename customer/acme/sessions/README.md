# sessions/

Working-session logs for this customer: what was tried, what an `autopkg run`
printed, what was decided and why. One Markdown file per session
(`session-NNN-<topic>.md`); format in `.devagent/rules/07-sessions.md`.

Gitignored except this README: session logs routinely contain hostnames, user
names and ticket numbers. Distill anything durable into a recipe README, a plan
in `plans/`, or the kit's `reference/methodology.md`.
